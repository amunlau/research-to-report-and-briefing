# 验证范围与复核方法

本页记录3.0.0的实际检查、仓库中可复用的回归与旧版历史验证，以及仍需在实际环境中完成的工作。历史结果只对应当时文件，不能自动证明后续修改仍然通过。

## 仓库内可运行的检查

从包含 `SKILL.md` 的目录执行。命令中的 `python` 替换为实际的 Python 3.9+ 解释器，例如 Windows 的 `py -3` 或 Linux 的 `python3`；以下命令均不需要第三方 Python 包。

| 命令 | 检查什么 | 不证明什么 |
| --- | --- | --- |
| `python -B scripts/setup_skill.py check` | 必需资源、内部文件引用、JSON、Python 语法及环境候选 | 完整 Agent Skills 规范、宿主已加载、引擎可用或版面正确 |
| `python -B -m unittest discover -s tests -p "test_*.py"` | 当前五份测试文件的完整回归，使用本地隔离夹具 | 真实研究质量、Linux实机、宿主加载或Office渲染 |
| `python -B tests/test_project_memory.py` | 27 项项目记忆回归，使用隔离临时目录 | 内容审计、PPTX 提取与安装助手的全部行为 |
| `python -B tests/test_runtime_helpers.py` | 14 项内容审计、PPTX 提取及安装行为回归，使用隔离夹具 | 事实真实性、完整OOXML规范、宿主加载或实际PPT渲染 |
| `git diff --check` | 未暂存修改的空白问题 | 逻辑、事实、安装或运行正确 |
| `git diff --cached --check` | 暂存修改的空白问题 | 同上 |

`tests/test_project_memory.py` 覆盖初始化、原稿保留、显式迁移、配置校验、交付范围、快照身份及失败回滚。`tests/test_runtime_helpers.py`覆盖纯报告无需deck、证据素材来源继承、文件缺失、来源未读、引用错误、假设限定、备注开关、字段与单元格引用、PPTX原生文字/备注/显式换行、损坏结构、输出防覆盖，以及安装保留既有不同内容。安装测试仅复制到临时位置，不更新用户的技能目录。

后续补充的`test_content_audit_edges.py`覆盖可选素材指纹、传递依赖、限定语可见性、同段富文本及独立正文边界、ID作用域和引用循环；`test_memory_install_edges.py`覆盖读取中替换、快照绑定完整性、原字节保留、无变化分支的候选类型校验与安装失败回滚；`test_pptx_identity.py`覆盖PPTX正常文件与等长、保留时间的替换检测。也可用`python -B tests/<文件名>`单独运行相应文件。

对已有研究项目，可按需求使用[内容审查](../references/content-contract.md)和[PPTX 提取](../references/ppt-production.md)助手。先查看对应脚本的 `--help`，传入真实项目文件；没有材料时不要为取得“通过”而制造空账本。

## 需要在实际任务中确认的部分

- **宿主加载：** Codex 与 Claude Code 是否发现正确目录、实际加载哪一份同名技能；安装助手的候选发现不能代替此项。
- **平台组合：** Linux 实机、不同 Python 版本及宿主组合；Windows 中完成的检查不自动覆盖这些环境。
- **PPT 成品：** 制作引擎、字体、原生对象与备注保真，以及最终 PPTX 在目标应用中的渲染。3.0.0本轮检查未完成整套制片或实际Office渲染；此前2.0.0所列检查也不能替代此项。
- **研究与讲述：** 引用是否支持论断、技术机制和比较条件是否正确、页面是否易读、备注是否自然，以及全场实际用时。结构扫描与文字样稿不能替代这些判断。
