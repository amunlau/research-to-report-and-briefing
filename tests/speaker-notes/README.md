# 专业口语备注与来源按需输出

这组封闭材料验证讲稿表达、来源记录与展示位置的分工，不是PPT渲染或听众效果测试。材料及文件定位均为虚构教学设定，只供追踪输入身份，不表示真实产品采用该机制或对应文件已存在。

执行者只读当前`SKILL.md`、任务相关参考和`inputs.json`，按各项任务给实际答案，不读取`expectations.json`、旧答案或评审记录，不联网补事实。执行后再由审阅者对照语义预期检查专业准确性、能否自然讲述、页序/读序、书目默认不进入备注、按需补来源及关闭备注的边界。不同措辞、句长和段落安排均可成立，不按禁词、字数、批注数量或某个模板句评分。

五项覆盖默认两页技术讲述、明确要求备注附来源、仅要求页内引用、明确关闭备注，以及旧书面稿/来源分区迁移。来源定位、条件和断言强度与口语化分别核对；增加语气词不代表完成，删书目不代表可删除来源记录。模型对纯文本/结构化答案的复核不能证明实际PPTX备注写入、作者试讲或真实听众理解已通过。

另有[页面与备注联动任务](alignment-inputs.json)，四项分别覆盖讲稿反向补页、只改备注时的流畅口语与页面保护、普通全场软目标、明确不可延长的硬限时。执行者只读该输入及当前技能相关规则，不读[语义预期](alignment-expectations.json)或旧答案。验收看实际页面规格与讲稿是否互相支撑、复杂过程是否讲清、时间冲突是否如实处理，不靠固定句式或“已对齐”自评。两组材料可按改动范围分别复测，不默认每次全部重跑。
