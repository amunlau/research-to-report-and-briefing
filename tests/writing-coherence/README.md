# 中文段落组织与衔接的行为回归

这组材料验证起草、普通润色、结构整理与仅审阅中的编辑判断，不是自动语言评分器。`inputs.json`提供独立任务与原文，`expectations.json`仅供完成后的语义核对，不交给试用者。前者的T案例为虚构教学材料；SambaNova四项使用用户提供的同一原文，不表示其中产品、公告和数量已经外部核实。

## 使用方法

让未参与规则编写的执行者读取当前`SKILL.md`及任务相关参考，逐项按`task`与`text`交实际答案；不读取预期、旧输出或评估记录，不联网补事实。随后对照预期和实际答案，核对定位、应保留表达、对象与关系、数值/限定/引文、修改权限及最终版本。允许多种正确表达、零项意见和有理由的待核状态，不按关键词、批注数量、固定段数或指定标题评分。

T01—T15覆盖多候选与明确回指、合理省略、多主体流程、时间阶段、多指标比较、场景与约束、商务插入、规划数量与引文、单段摘要、三种修改权限、源换行、可猜但回找困难以及正常表达；T11分成三项权限任务。SambaNova另测只审阅、普通润色、结构整理与依据材料起草。T16将初次独立未见试用中的因果疑点纳入后续回归，检查普通润色不扩大科学主张修改权限，默认最简定位待核。T17保留提交前独立试用中的明确输出限制：用户禁止附注时只交正文，仍不擅改主张或宣称核实。当前共23项任务，可分批执行，分别保存执行版本、原始答案、实际发现和复查。

不把同一批材料既写规则又复测后的结果叫作未见验证。另请未读规则和预期的材料作者编写其他领域的封闭输入，执行者仍看不到评判答案；主审阅者阅读真实输出后记录误报、漏报与保真/权限问题。发现缺陷后做针对性回归，旧输出保留，未执行项不写通过。

本目录不含调用模型的自动脚本；现有Python单元测试也不验证自然语言判断。文件结构与实际排版另按最终Word、PPT、Markdown、TXT或LaTeX交付物检查，不能从纯文本夹具宣称Office渲染或真实听众理解已通过。
