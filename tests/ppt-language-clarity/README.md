# PPT用语与理解对应的行为回归

八项封闭文本任务覆盖索引前提、容量与证据身份、跨页算例、观察与因果、时间线、信息不足时仅审阅、正常表达保留，以及完整授权内的页面和备注共同修订。测试材料全部是虚构夹具；其中标为“公布参数”或“测试记录”的条目模拟各自身份，不是现实产品证据。

执行者只读取当前`SKILL.md`、任务相关参考和[输入](inputs.json)，不读[语义预期](expectations.json)、旧答案或评审记录，不联网补事实。先保存实际答案，再由审阅者结合原材料复算、检查语义与授权范围；不按关键词、固定句式、字数、发现问题数量或“已对齐”自评判定。各案例独立执行，互相的对象和条件不能串用。

观察可以只有有依据的描述，正常文本可以无修改；不以有无结论句、逐页排除说明、完整术语表或三张检查表评分。需要看页面的关系不能只放备注，尚未定义的技术对象不能猜补，原有专业口语和来源展示规则继续适用。不同写法与图文布局均可通过。

这些任务不生成实际PPT，不检验字体、遮挡、原图质量或真实听众理解，也不代替既有Python回归。执行范围与结果记录在[验证说明](../../docs/validation.md)，原始答案及评审留在仓库外；可以按变更范围选取相关案例，不要求每次重跑全部历史材料。
