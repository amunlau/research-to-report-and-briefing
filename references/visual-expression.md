# 图表与视觉表达

用于设计或检查复杂框架、数据图、技术表格和原图展开，也适用于市场趋势、项目进展与决策汇报。先确定图中对象与关系，再选择版式与样式；页面密度、材料分工和讲稿方法见[汇报与作者学习](briefing-and-teaching.md)，页型选择见[技术、市场与工作汇报页型](slide-archetypes.md)。原图解析沿“调研与证据”的来源和标号记录进行；最终文件的编辑性和渲染检查见[PPT制作](ppt-production.md)。

## 素材选择与来源保真

先明确本图承担的任务：展示真实对象、提供测量证据、解释已核实关系，或帮助建立概念。不同任务采用相应素材：

- 产品外观、芯片封装、设备内部与实际拓扑，优先用户原始素材、厂商技术资料、标准和论文原图。
- 精确量值、性能与分布，优先原图或由可复算底表生成的数据图。图像生成模型不提供测量数据。
- 已知组件关系可用原生形状、确定性绘图或经核查的重绘；逐条检查模块、方向、连接数和标签。
- 生成式图片用于合适的概念说明或视觉草案。记录生成属性，检查文字、连接和对象细节，不将其当作产品实物或技术证据。没有每页生图或最低生图张数要求。

每个素材记录asset ID、source ID、来源定位、原图/派生/重绘/生成属性、用途、原始尺寸、裁切区域、保留标签及对应fact ID。沿用项目证据台账；原始文件保留，裁切与标注另存派生版本。候选图不足时标记具体缺口：缺原图、分辨率不足、编号不明或技术含义未核实，不以无关科技图片填充。

依次尝试原出版附件或源图、论文源文件、网页原尺寸图片、相关PDF页高分辨率渲染。PDF直接抽取的image可能只是复合图的一块，须和整页、图注对照后使用。导出矢量容器也可能包含栅格区域，不能只凭扩展名判断清晰度。

入版前确认素材实际支持本页要解释的内容，并保留相应的实验、产品或统计条件。已提取成功只说明拿到了文件；图注配错、局部面板缺失或关键标签不可读时，仍需处理后使用。关键图的直接观察与论证边界沿[调研与证据](research-and-evidence.md)登记；已有复杂原图可用解释文字、局部放大与清晰引线帮助阅读，无需重绘成简化卡通图。

## 建立适合技术内容的视觉系统

从参考稿提炼页面比例、内容网格、标题层级、正文与图内字体、语义配色、来源区域和表格规则，保存为项目配置。用户指定的品牌、模板和视觉要求优先；没有指定时，采用蓝色系的克制科技风：浅色背景、深色正文，以蓝色建立层级并标出讲述重点。密集页优先保证文字、细线与原图的对比度；不靠装饰性发光营造科技感，也不默认使用深色整页。深色页可按品牌、内容和展示环境选用。

中文标题、正文、原生表格与新增中文注释默认采用微软雅黑（Microsoft YaHei）；明确的品牌、模板或用户要求可覆盖。制作前确认目标环境可用，缺失时选择可用的中文替代字体并记录，导出后检查断行和字形。数学公式采用适合符号与排版的数学字体，代码采用适合阅读的等宽字体，专业原图内字体保持原样，不为统一外观强制替换。字号由观看距离、内容层级和最终输出校准，示例中的具体数值只是编辑起点。

蓝色作为默认基础，可按分类、关系和讲述重点加入协调的青绿、暖橙、紫色或其他辅助色；配色不限定为蓝灰，也不要求每页用完选定色板。风险、告警、完成状态等保留清楚的语义色，并辅以文字或符号。保留专业原图中有意义的颜色，不将所有图重染成蓝色。图表的数值、单位和标签避免多种字体无意义混排；红绿区分同时提供文字或线型。

扩展配色时先确定颜色的职责，再决定色值与面积：

- 中性色承载大面积背景和正文，主色维持标题与总体层级，辅助色用于需要区分的类别或当前重点。相近色相可维持统一，较有反差的色相可形成焦点；具体组合按内容、品牌和实际观感选择，不规定色数或面积比例。
- 长说明优先用浅色底配深色正文，较强颜色可落在标题签、侧边条、编号或局部重点。实色面板按实际对比度选择文字颜色，不因使用浅底或白字就假定可读；渐变、纹理与透明叠加处也检查实际文字背景。
- 同一类别跨页保持相同含义。类别色、状态色和量值色阶各有职责；已有状态含义的颜色谨慎用于无关装饰，避免让普通类别被误读为风险、完成或优劣。标签、编号、线型或明确位置同时保留识别依据。
- 控制相邻色块的明度、饱和度和视觉分量，让主要依据与重要条件均可见。密集页可采用中性正文配局部彩色标识，避免所有块同时以高饱和底色争夺注意；也不以灰度弱化关键限制。

全稿保持字体、标题层级、基础网格、来源样式和语义配色的一致；在共享对齐线与间距体系内，按内容组合行列、跨列区域和图文比例，形成不同的正文构图。基础网格提供位置参照，不要求每页使用相同分栏。整套版式安排及相邻页面的取舍见下节。

## 全稿构图变化与连续阅读

**强烈建议在内容适配、可读性和讲述连贯的前提下形成适度的版式多样性。** 较长PPT尤其需要主动审视连续及邻近页面，避免长期复用相同图文位置、面积比例和要点组织。此项是设计偏好，重复是复审线索；不设版式数量、连用页数上限、重复率或自动拒收条件。用户模板与明确要求优先。

逐页计划形成后，按实际播放顺序一起考虑本页任务、素材有效长宽比、解释文字容量、主要视觉对象和读序。同一种页型也可采用不同构图；内容任务相同并不意味着默认复制相同几何。对明显雷同的一组页面，优先在独立话题、整体与局部、机制与比较、证据与归纳等讲述阶段切换处，内部考虑少量更适配的方案并选择。无需逐页列候选或增加用户确认；有需要的安排可沿用[内容契约](content-contract.md)中的可选构图记录。

| 素材与讲述需要 | 可选构图与适配重点 |
| --- | --- |
| 横向展开的架构、流程或电路图 | 全宽主图配上下解释区；先建立概念时可上文下图，先观察证据时可上图下文。保留图内标签的有效尺度，说明通过编号对应 |
| 纵向原图与较长解释 | 左文右图或左图右文，按读序、图形比例与文字容量分配栏宽；每页机械左右交替不能代替内容适配 |
| 一张主图有多个需要解读的位置 | 主图居中或占主体，解释靠近对应位置，用编号或引线建立读序；长解释另设宽区，避免围绕主图形成难读的碎片 |
| 需要从整体定位到局部细节 | 总览图配局部放大、关键面板和相应说明；整体保留定位作用，局部保留真实标号与上下文 |
| 多个对象或方案按共同维度展开 | 图文成组对照、比较矩阵或表格配关键图，保留可比尺度与字段；组数按实际对象确定 |
| 一个问题由多组证据或分类说明支持 | 中间放简明问题或主旨，外围图文分组，标明对应与阅读顺序；空间居中不自动表示技术中心，长段解释不塞进狭小中心区 |

文字组织也随内容变化：步骤配对应解释、分类条带、编号注释、对照字段、条件与结果说明均可采用。不把不同内容固定整理为三个小标题加三个段落，也不通过任意增减要点数制造差异。不同页型名称、换色或左右镜像都不足以证明最终构图已有适合内容的变化。

稳定布局有明确用途时保留：同一系统的连续状态展开、逐步推导、同口径方案比较和跨页长表，需要稳定的对象位置、标号、图例、分类顺序及数据尺度。优先在这些完整讲述单元之外安排变化。局部重点可随当前讲述移动，原图内的真实结构和方向保持不变。

成稿后查看实际PPTX产生的缩略图总览，并连续翻阅相关页面：观察图文方位、区域比例、说明块组织和视觉重心是否反复相同，以及新话题是否有清楚入口。缩略图用于发现整套重复模式，逐页查看用于判断替代布局是否确实更易读、更适合讲述。需要修改时调整制作源并重新导出；保留完整解释、原图证据和可读字号，复查宽度、换行、留白、图文对应与备注顺序。纯装饰变化、无任务的过渡页或缩字删解释不作为解决办法；具体验收见[质量与版本](quality-and-versioning.md)。

方法参考（2026-10-21查阅）：

- [Duarte的版式选择建议](https://www.duarte.com/blog/secrets-to-choosing-designing-unforgettable-visual-aids/)强调随主旨选择不同布局，避免整套只用一种结构；其[全稿审阅方法](https://www.duarte.com/blog/working-with-executives-on-presentations/)建议使用墙面或幻灯片浏览视图观察整体结构。本技能将总览方法用于观察构图重复，不将其解释为重复率标准。
- [微软SmartArt布局指南](https://support.microsoft.com/en-us/office/graphics-visuals/choose-a-smartart-graphic)将信息关系、文字量及摘要与细节的位置作为选择依据。
- [Autodesk布局系统](https://brand.autodesk.com/visual-system/layout-system/)采用灵活网格与统一对齐组织变化。本技能借鉴共享对齐线、间距与可变分区的方法，不照搬其品牌色、网格单位或面积比例。

这些方法用于改进选择与审阅；技术汇报所需的完整解释、专业原图和阅读支持继续按本技能要求保留。

## 图文共同完成讲述

页内文字交代图表的对象、条件、读法和含义；图表给出文字所指的结构、差异或证据。解释可以使用完整要点、短段落和按意义分类的项目符号，不把完整意思拆成孤立关键词。每条要点讲清一个关系或动作，必要的主语、条件与限定保留；类别依据内容建立，不要求每页恰好三点。

标题可以概括本页内容、提出待回答的问题，或表达已有证据支持的观点，选择取决于本页在全场中的作用。解释原理、建立背景或说明范围的页面，标题直接交代内容即可；各页共同服务全场主旨，不要求每页标题都是结论句。内部记录的 takeaway 表示听众本页需要获得的理解，不必逐字成为标题。常规内容页优先让本页具体主题获得清楚的视觉层级，章节名称承担导航；避免章节横幅十分醒目，而具体主题只留在角落的小字中。用户指定的母版层级优先，在其可调区域建立本页焦点。

优先复用能形成解释关系的组合：规格表配结构图，让参数落到对象；解释文字配关键原理图，说明操作与结果；比较表配条件说明，揭示差异成立的范围；风险或进展矩阵配决策事项，说明下一步由谁处理什么。组合可改变左右位置和面积，不以统一卡片数或等宽网格限制内容。

页数按内容范围、听众基础、讲述时间和材料用途确定，不设固定范围。先删重复、补读序、调整图文比例；仍不能在目标尺寸读清时，放大局部、分步展开或拆页。借鉴样本的结构和解释方法，具体型号、字体大小与页数由当前任务决定。

## 说明性文字也需要视觉组织

多组说明、观点和条件默认按语义主动分组，使听众能迅速找到组别、重点及讲述顺序。文本框较多时，强烈建议主动选择合适的视觉处理，改善组别辨认与扫描阅读；已有清晰层次的页面可以保留简洁表达。先依据本页角色组织概述、主体或归纳等区域，再安排模块内部的标题、完整要点和必要条件；有框分组与无框的编号、加粗引导语都可采用。

- 用小标题或标题签命名组别，正文按完整语义拆成项目符号或短段落。保留主语、机制与条件，不把自然解释拆成几个零散词。
- 同组内容通过邻近、共同底色或边界建立归属；不同组之间有清楚间隔。统一同级模块的标题层级、内边距、对齐线与项目符号缩进，长行换行后与正文起点对齐。
- 加粗引导语突出对象、动作或判断，后接必要解释；编号表达阅读次序或步骤，需区分编号次序与实际因果。勾选、警告等符号有状态含义时必须与事实一致，普通列举可用中性项目符号。
- 根据内容长度分配模块空间。短节点配邻近的完整解释，长解释采用条带、纵向列表或独立说明区；不要把长段落强塞进小圆、箭头或狭窄多列。解释区用稳定编号、颜色加标签或清楚的位置关系对应节点。
- 产品或方案介绍可把“名称—图片—说明要点”纵向成组，各组共享对齐线；问题分析可采用“概述—分类模块—综合说明”；已有清楚层次的编号说明可保持无框。分组形式服务当前信息，不固定卡片数量或要求每段文字加框。

可在已有分组上选择下列处理；它们是表达选项，关系结构仍按下一节确定：

| 文字与阅读需要 | 可选表现 | 使用重点 |
| --- | --- | --- |
| 多组完整解释需要快速区分 | 浅底面板、标题色带、侧边色条或细边框，内部配完整项目符号 | 可只强调组名，正文保持较宽阅读区；同级组共享标题和缩进规则 |
| 步骤连续、每步解释较长 | 编号列配说明条带、纵向步骤与相邻说明 | 序号承担定位，连接线只表达真实先后或传递；无需把长段文字放进箭头 |
| 术语、类别或对象名称配说明 | 左侧标签栏配右侧解释、图标加标题再接正文 | 图标含义清楚、风格协调，并保留文字标签；不能用通用科技图标冒充专业结构或替代解释 |
| 对象较多，需要按同一维度比较 | 对齐的字段行、成组对照栏或分区矩阵 | 按共同维度扫描，精确数据保留表格；文字长度不必相等，也不用颜色暗示未经证实的优劣 |
| 关键判断需要和支撑材料联系 | 局部重点框、带标签的引出说明、主体与支撑块 | 判断与适用条件同样易读；用位置、编号或清楚引线联系依据，避免强调框与正文脱节 |

面板、标题签、符号和图标按实际需要组合；普通说明无需同时叠加厚边框、强阴影、亮色底与装饰图标。相同层级的圆角、线宽和图标风格应协调，圆角或阴影本身不构成必选样式。项目符号优先采用引擎支持的列表与悬挂缩进；绘制自定义标记时保留稳定的续行对齐，不用空格或逐行拆框模拟。

背景与装饰线应位于内容下方，文字保持原生可编辑；图标的表现和对象支持按制作引擎核对，不能依赖目标环境缺失的符号字体。增添色条、编号列、图标或更换框形后，重新计算内部可用宽度、内边距、段距和框高，检查实际PPTX换行；不能只扩大外部底块或用缩字补偿占用。仅增加框或底色仍可能留下段内无重点、上下割裂或图文难对应的问题，完成后要沿实际讲述顺序检查。整页空间与内容偏少时的调整见[布局与呈现工程](layout-engineering.md)。

方法参考（2026-10-21查阅）：[微软SmartArt指南](https://support.microsoft.com/en-us/office/graphics-visuals/choose-a-smartart-graphic)用于按关系与文字容量选择结构；[Duarte的设计原则](https://www.duarte.com/blog/4-presentation-design-principles-to-live-by/)用于保持颜色含义与注释重点；[微软可访问性指南](https://support.microsoft.com/en-us/accessibility/powerpoint/make-your-powerpoint-presentations-accessible-to-people-with-disabilities)用于文字背景对比及颜色之外的识别线索。本技能将这些原则适配为上述文本组织建议，保留技术汇报需要的完整解释、密表和专业原图，不据此加入固定字数、色数、形状数或字号门槛。

## 关系决定布局

先用“对象—关系—对象”写出本页要表达的结构，确定入口、主要阅读路径与结果位置；并列说明可以直接列明分类依据。结合对象数量、文字长度、解释深度和原图需求选择构图。SmartArt式表达借鉴按消息选版式的方法，实际可用原生文字、形状和连接线；不要求生成真正的SmartArt对象，也不以整页栅格化换取样式。

| 信息关系 | 可选构图 | 文字与关系处理 |
|---|---|---|
| 并列、分类 | 分组列表、条带、标题签模块、分类矩阵 | 同级分类依据一致；短项可横排，长解释优先纵排或较宽说明区；无先后关系不加流程箭头 |
| 顺序、阶段 | 编号流程、阶段带、纵向路径 | 短节点标动作，完整解释贴近相应步骤；区分阅读次序、实际执行和真实时间间隔 |
| 层级、组成、归属 | 树形、嵌套分组、分层区、泳道 | 标签写清层级或责任，同级对象职责可不同；深层树与长说明可分区呈现 |
| 依赖、传递、交换 | 节点连接、分区关系图、主路径加支路 | 标明输入、输出、方向和分支；只有真实的中心对象才采用中心辐射布局 |
| 循环、反馈 | 循环路径、主流程加反馈支路 | 写清反馈对象与条件；不为视觉闭合把单向过程画成循环 |
| 对比、评价 | 对照模块、图文列、表格、比较矩阵 | 共享维度、基线与条件；解释可独立成区，精确参数保留表格，不强求所有内容等长 |
| 共享、交集 | 共享资源区、重叠区域、使用关系表 | 区分各自独有和共享部分；维恩图只表达真实交集，面积没有量值依据时不承担数量含义 |

组合关系时先决定并列、嵌套、交叉或共享的空间关系。例如一条执行路径跨过多个责任主体，可用流程叠加泳道；每个步骤仍有清楚归属。依赖可以通过邻接、对齐或包含直接读出时，采用这些关系；确有传递或反馈时再画相应箭头。

示例：两个阶段共用同一份参数记录，可以把该记录放在共享资源区，并分别标明读取或生成关系。若公开资料只说明共享，图中便表达共享；双向连接只用于确有往返交互的过程。

结构确定后，再安排节点、必要连线、标签和强调。颜色持续标识同一对象，同时用文字或稳定标号保留对象身份。图、公式和解释通过同一编号、同名变量、带标签的颜色或邻近位置建立对应，避免让听众仅凭段落先后猜测。引出标签的细线与表示技术关系的箭头采用可区分样式。标签写明对象或动作，注释解释本页相关机制；“高效协同”“强大支撑”“全面赋能”等没有具体所指的标签应改为真实功能或删除。

复杂关系页或明显失衡的页面可内部比较少量构图，按关系准确、文字容量、读序和主体协调选择；普通页面直接使用适合的布局，无需逐页提出候选或增加确认步骤。实际使用SmartArt或切换图形布局后，核对全部文本、层级、节点和连接是否保留，防止隐藏内容或自动缩字削弱解释。

## 检查几何承载的含义

将版式当作论证的一部分检查。关系图中的中心节点可能表示中心地位，等大和对称可能表示等权，嵌套表示归属，闭环表示循环或反馈，双向箭头表示互相作用。根据真实关系设置形状、方向和空间分配；单纯用于容纳文字的区域，通过标题和对齐说明分工。整组内容在正文区域居中只是页面构图，不因此把某个节点改成技术中心；组内多行解释和项目符号通常仍左对齐。

制作记录中完成以下复核：

1. 图中每个组别、层级、方向和共享区域均能对应资料或明确分析。
2. 重要程度、数量或顺序的差异在空间表达中准确；仅为适应文字而调整的尺寸不承担数量含义。
3. 去掉装饰、阴影和强调色后，主要阅读路径仍成立。
4. 每个标签、注释和来源归属到正确对象；交叉、遮挡与边界不改变连接关系。

## 数值到图形的转换

只要数值决定位置、长度、角度、面积、半径、宽度或色阶，就记录底表、单位、范围、基线和编码公式。微型图、插图及多个并列小图采用同样方法。按“数据与口径→坐标或编码→计算图形→标签与注释→样式”的顺序制作。

先确定要让听众看到的是量值比较、时间变化、分布、变量关系还是区间不确定性，再选择图形。分类比较可用点位或柱形，连续变化可用折线，分布和不确定性需要保留相应形态与范围；精确参数与多条件对照仍可用表格。不要为形式多样而给没有连续含义的类别连线，也不要用平均值掩盖决定判断的分组或波动。

- 比较数值大小时优先使用容易辨认的共同位置或长度；柱形的量值长度从零开始。区间、变化和对数图按其明确的分析目的设置刻度，并显示刻度方式。
- 多个可比较面板保持一致的尺度、分类顺序与单位；确需不同尺度时直接标明，解释所比较的关系。
- 面积图形按面积映射数值。示例：若圆面积表示4与9，半径比为2∶3；半径本身表示数值时采用另一条明确标注的编码。
- 堆叠、累计、百分比和派生指标先计算，再生成几何；保留分母、汇总规则、精度及缺失值处理。
- 色阶或分档说明变量、方向和分档边界；强调色指出已有证据中的关键对象。

缺失、零、排除和低于检测范围分别处理。时间或序列中有缺口时，检查绘图工具是否跨过缺失行自动连线；按实际含义显示断点、分段或明确标注的插值。平滑、标准化、基线扣除和对数变换会改变读法，保留处理方法及必要条件，不把处理结果当成未经变换的原始测量。

含统计比较时说明独立分析单位、样本量和误差条或区间含义。相同对象的重复观测不能直接冒充多个独立样本；标准差、标准误、置信区间和预测区间按实际计算表达。用模型结果支持选型时，根据所作判断检查留出条件、误差分布、校准或外推范围；参与模型选择的数据不能再次称作独立外部验证。没有这些任务时，不强制新增统计图。

检查底表正确性与图形编码正确性：选取端点、关键点、累计值和异常值核对其实际位置或比例。原图直接采用时，读清它原有的尺度与基线；裁剪、放大和重绘后保持量值关系。直接标注决定本页判断的数据点、区段或基线，减少来回查图例；标注写出有依据的数值、事件或关系。

## 表格的行列语义

先写明“每行是什么对象、每列是什么属性、交叉单元回答什么”，再建立完整表头、单位、比较条件和必要注释。参数表、方案矩阵和分层记录表分别服从自己的行列关系；独立段落或指标卡可采用分区布局。

列宽与行高按属性含义和实际内容分配。可比数字采用一致单位、精度和对齐方式；文本保留清楚的字段归属。合并单元用于真正共享的标题或组别，连续行列仍可追踪。状态符号和等级配明确含义，证据不足或不适用的单元按实际情况区分。

先检查普通文本状态下能否准确读表，再增加分隔线、底色和重点行。趋势、分布和量值对比可用图帮助识别，精确值、属性组合和条件差异保留在合适表格中；按任务组合使用。

参数表应同时说明参数含义、作用对象和计数范围，例如“单芯片”“单节点”“双向合计”；不能把不同层级的带宽直接放在同列比较。空缺、零、不适用和厂商未披露用不同状态记录，避免统一用破折号掩盖差异。需要后续增删行列时采用原生表格；若因复杂排版拆成形状，交付时如实标记。

原生数据图表保留数据工作簿或等价可编辑数据源；仅将柱子画成可编辑矩形不能声称图表数据可编辑。源图没有完整数值时优先保留原图，不以目测补出精确底表。

## 原图与连续状态

复杂原图先说明在系统中的位置，再沿关键路径解释局部。高亮、局部放大和引线保留原有标号及对象对应；新增注释附着于原图中的真实依据。原图标签、原始内容与当前作者的解释在样式和来源说明中可辨认。

多面板图先建立“面板标签—问题—条件—主要结果—目标页”的映射。保留支撑本页判断所必需的坐标、单位、图例、样本/误差说明和原面板编号。裁去面板时检查共享图例与统计注释是否被连带删除；多个面板来自不同来源时分别标注，不能通过拼接暗示它们属于同一实验。一个面板只显示局部时附必要的全图定位或范围说明。

同一过程需要分步展开时，可以连续复用同一原图：保持主要位置、比例、裁剪或概览定位图，以及稳定标号，每页只突出本次新增操作或状态变化。延续已解释的对象，记录本步输入、变化与输出；省略的中间步骤在讲稿或详解中能够追踪。连续状态可以用普通多页呈现，是否使用动画由交付环境决定。

构图完成后，按目标媒介的实际显示或阅读尺寸检查关键标签、关系和标注；需要会后独立阅读时，再核对页面能否独立传达主要判断。图内文字也计入可读性要求，不能只检查页面正文。投影用主图若必须放大到200%才读清关键端口、轴值或线路标签，应取得更清晰来源、放大关键局部或分状态呈现；提高低分辨率图片的像素数不会补回原始信息。

栅格图的有效清晰度取决于原始像素与最终占用尺寸；只修改DPI元数据不能增加细节，图中的局部位图也需单独判断。矢量细线、下标、图例和透明区域在实际导出后仍可能失真，按最终展示尺寸核对。字体测量、图片适配与裁切的具体实现见[布局与呈现工程](layout-engineering.md)，不为填满图片框裁掉科学图的证据部分。

在最终PPTX渲染图上同时看整页读序和局部细节：主图轮廓、关键标签、交叉连线、颜色图例、符号上下标、表头与来源区域。局部放大检查不能替代实际展示尺寸判断。修正后重新导出对应页面，避免只修源SVG或HTML预览而未更新成品。把读图、几何和表格检查结果写入制作记录；成品页面直接呈现清楚的技术关系。
