# 调研报告的字体、段落与章节编号

制作或检查调研报告时读取。本文件规定报告的默认格式，适用于报告单独交付及报告与PPT成套交付；明确的用户格式、投稿规范或指定模板可覆盖，并记录实际采用项。PPT沿用[视觉表达](visual-expression.md)的字体与配色，不把两类成果共用一份文字样式。

## 默认样式

| 对象 | 默认要求 |
| --- | --- |
| 全文中文标题与正文 | 宋体（SimSun） |
| 全文英文标题与正文，以及普通西文数字 | Times New Roman；中英文混排分别落实字体 |
| 标题与正文颜色 | 黑色（000000），包括封面主副标题、各级章节标题与正文；不继承蓝色标题、彩色副标题或灰色正文 |
| 正文主体段落 | 首行缩进两个字符，以段落格式实现；正常字重为主 |
| 正文各级标题 | 使用真实标题层级；章级标题必须有可见一级编号，下级编号与其对应 |

字号、行距、段距和页边距按用途与明确模板选择，保证上述默认值在实际成品生效。标题以字号、字重、间距和编号建立层级，不靠彩色文字区分章节。普通段落设置真实首行缩进，不插入两个空格或全角空格模拟。标题、列表、表格单元格、独立公式和图注按各自语义排版，不机械套用主体段落的首行缩进。

数学公式、代码及专业原图内的字体按用途保留；原图和数据图的有效颜色编码不随正文黑色要求被清除。这里的例外不能用于保留普通标题的主题蓝色或整段英文的默认无衬线字体。

## 编号与目录

正文章级标题选择“第X章 标题”或“X 标题”作为全篇一致的一级编号形式；下级按相应章节使用“X.Y”“X.Y.Z”等层级。章序与标题层级匹配，不能用项目符号代替章号，也不能出现章标题无编号、下面直接从“4.1”开始的情况。封面总标题与目录标题不充当正文章级标题；摘要、结论等若组织为正文中的一章，同样进入所选章序。

标题、目录、交叉引用中的显示编号保持一致。稳定内容ID（例如C004）用于内部追踪，不代替读者可见章号；重排章节时更新显示序号、下级编号和引用，保留原内容ID。采用自动多级编号时绑定正确的标题样式；采用显式编号时由同一章节顺序生成，避免自动编号与手写编号叠加。

## 制作与导出

开始排版时先设置正文、封面标题、各级标题和目录的实际样式，再填入内容。按当前工具设置东亚字体与西文字体，并检查主题、模板、直接格式和编号文本的继承；仅设置一个默认字体或写一句“使用宋体”不代表中英文都已正确。将导入内容和旧模板残留的蓝色、字体及缩进覆盖回本次采用的样式。

Word等富文本文件使用段落与标题样式实现；HTML等受控排版使用中西文字体映射、黑色文本和两个字符的首行缩进，再核对实际字体解析。PDF从正确排版的源文件导出，复查字体替换、分页及可见编号。仅交付纯Markdown时，保留正确标题层级与可见编号；字体、颜色和段落缩进受阅读器控制，不能声称已强制实现，也不为此擅自增加交付格式。

制作前确认字体实际可用；缺失时优先使用具备所需字体的可用环境。确需采用替代字体时记录实际字体与未满足项，不能将替代结果记为已满足宋体或Times New Roman。最终以真实文件打开或渲染结果核对，而不是只看生成参数。

## 验收

检查最终报告全文的标题与正文：中英文混排、封面主副标题、不同级标题、普通段落的首行缩进、章序及目录引用。结合有效样式检查与实际逐页阅读，关注字体继承、蓝色标题残留、主题色、手动空格缩进、章号丢失或重复。格式修复后重新导出并复查受影响页面、目录和交叉引用；检查身份与记录沿用[质量与版本](quality-and-versioning.md)。
