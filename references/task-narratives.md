# 任务与论证路径

用于市场趋势调研、技术细节调研和工作汇报。先明确本次希望读者理解什么、判断什么，以及是否需要作出决定，再选择论证关系。下面的路径可合并、重排或局部使用，不是固定目录或页数配额；纯知识分享可以止于有依据的认识，不必硬凑行动建议。

## 市场趋势调研

**可选论证链：变化 → 证据与驱动 → 分歧及情景 → 影响与判断。**

- 从当前问题定位变化：是需求、供给、价格、采用率、竞争格局还是价值分配在变，时间范围与比较基准是什么。历史序列说明发生了什么，横向比较说明变化是否集中于特定地区、客群或环节。
- 将观察证据与驱动解释分别展开。趋势同向不自动构成因果；用供需机制、约束变化或可定位事件说明驱动怎样传导，并检查替代解释。
- 来源发生分歧时，核对口径和预测假设。情景围绕会改变判断的关键变量展开，说明触发条件与影响路径；不为凑高、中、低三档编造增长率、概率或拐点。
- 回到用户关心的影响：哪些需求或约束可能改变，哪些判断仍成立，什么新证据会促使调整。需要选择时，给出与当前资源、窗口和风险相匹配的选项；没有可靠依据时保留待观察条件。

证据保留时间、地域、样本或覆盖范围、指标定义、币种与价格口径等相关条件。区分存量与增量、名义与实际变化、公开目标与实际完成值、历史数据与预测；预测转述保留发布机构、发布日期和假设，不能写成已发生事实。资料截止点与最新数据覆盖期分别交代。

## 技术细节调研

完整报告与技术汇报的第一版默认按[关键技术深剖](report-and-explanation.md#关键技术深剖的默认要求)展开：以能体现对象价值的实现差异选择技术点，不设数量配额；结合详细原理/框图、步骤配文和效果证据讲到相邻领域人士可理解交流。市场或工作汇报中承担关键价值判断的技术部分也采用这一标准，纯背景概念按其作用简述。

**可选论证链：问题与约束 → 原理和机制 → 实现比较 → 效果与边界。**

- 先定义要解决的任务、输入输出和决定方案的约束，让读者知道为什么需要这一机制。
- 用原图、过程或小算例解释一次操作，再把算法、数据结构、器件、接口和运行状态接起来。展开到足以支持本次判断的层次；公开资料未披露的实现保持未知，通用模型明确为解释模型。
- 比较方案时采用同一任务和相关维度。隔离单个机制的影响与比较各自优化的系统是不同问题，分别说明控制条件、资源和质量约束。
- 将局部效果连接到系统结果、成本与适用范围。需要技术选型时，给出能区分候选的依据及关键缺口；用于教学时，以读者能追踪过程和解释条件变化为收束。

关键数据定位到原文、图表、代码或计算输入，区分标称规格、实测、估算和本次推导。结构图与规格表可以并置互相解释，结果表保留测试条件；实现细节与计算方法见[报告与机制解释](report-and-explanation.md)。

## 工作汇报

**可选论证链：目标与进展 → 结果和偏差 → 原因与措施 → 所需支持或决策。**

- 以已约定目标、范围、里程碑或验收标准为基准，说明本周期取得了什么结果。区分活动、产出、已验证效果和实际影响，不用会议次数或任务数量替代目标达成。
- 对结果与计划的差异交代影响范围。工作流并行时可按同一对象维度列出进展、交付物、依赖与风险，让读者能横向查看一个项目、纵向比较同类问题；不要求全部页面都使用该表格。
- 原因分析区分已有证据与待验证解释，措施对应具体原因、预期作用和后续检查点。负责人、期限及资源需求采用实际约定，未定事项如实标明，不补造安排。
- 需要支持时说明请求决定什么、可选方案、依据、代价及时间影响，使前文的技术方案、资源、计划与风险共同支持请求。普通进展同步可收束为下一步和待观察事项，无需制造审批请求。

进展依据来自对应版本的交付物、评审或验收记录、实际测量和项目记录；状态保持可区分，如已完成编写、待评审、已验证、已交付。预计完成时间与实际完成时间分开，材料尚未证明的收益作为目标或预期表达。对外汇报按授权范围选择内部数据，不能为了故事完整公开未授权内容。

## 合并为全场主线

一份汇报可先解释市场变化，再展开决定方案的技术约束，最后说明项目进展和所需支持。各部分保留自己的证据要求，通过明确的依赖衔接；不必为使用三种路径而各造一章。

对全场及关键章节实际提出的问题，沿已有页ID记录“提出问题的位置 → 用于回答的证据或解释页 → 得到的回答 → 尚未解决的部分”。结果页应能说明它回答了前面哪一项；结尾回应原问题及其适用范围。证据只回答了部分问题时，相应收窄判断并交代剩余缺口，避免开场承诺解释机制，末尾却只有性能排名，或提出工作阻塞问题后只罗列已完成事项。这是内部论证检查，不要求把问题和答案反复写成页面栏目。

回扣方式随任务变化：市场研究将变化证据与驱动解释分开，说明哪些观察能区分候选解释；技术研究将效果对应到机制与比较条件，指出哪些条件尚未覆盖；工作汇报将结果和偏差对应目标，并说明措施怎样影响待决事项。局限必须指向会改变当前判断的范围、条件或证据缺口，不以“有待进一步研究”统一收尾。

当关键问题确有不同解释或调查路线时，可在内部比较各路线需要的证据、现有支持、反证和遗漏，再选推进顺序。无需固定备选数量，也不为制造张力预设反共识结论。证据已清楚、用户已给定结构时，直接沿既有主线组织。

每页标题可概括内容、提出问题或陈述有依据的观点，但应说明本页与全场主旨的关系。页内保留完整判断、条件和必要解释，项目符号、图表和短段落按关系选用；具体文字规则见[写作与编辑](writing-and-editing.md)。逐页备注默认形成可照读成稿，沿最终页面的读序展开，组织与同步见[汇报与作者学习](briefing-and-teaching.md)，时长安排见[时间预算](presentation-pacing.md)。
