# 页面与演讲备注共同设计

用于新建技术汇报、编写或修订逐页备注，以及页面与讲述脱节的修复。遵守入口的PPT核心约束；证据、密度、口语稿与时间分别沿用相关参考，不新增制作引擎、必填表单或固定句数。

## 核心约束：听众始终能找到当前讲述的页面落点

页面与备注共同承载同一条叙事。听众看着当前页面，应能辨认正在解释哪个对象、关系、操作或结果，以及它为什么与本页有关。备注可以补背景、类比、因果和必要推导，但不能长时间讲另一条页面上找不到对应关系的故事，再在结尾勉强回扣标题。题目相同、术语相同或开头说一句“看这张图”，都不足以证明贴合。

以**有完整意思的讲述片段**检查落点，不要求每句话都重复页面文字或说出空间方位。落点可以是可见的标签、数据、步骤、曲线变化、模块关系或正在呈现的状态；仅指向一个宽泛标题不能支撑长段技术分析。短转场和服务当前对象的必要背景可以暂时不增加图文；一旦出现连续的新对象、独立过程或必须记住的中间关系，页面就应提供相应支撑。判断依据是听众是否还能沿页面跟上，不设脱离页面若干秒、几句话或覆盖率的机械阈值。

备注的解释量服务本页理解任务：领域小同行能认清对象，跟上关键过程，读懂结果及其意义。封面和过渡页完成定位即可；复杂技术页应获得更多讲解，不要求每页讲遍全部基础，也不逐个朗读装饰、所有数据点或辅助参数。保留紧凑技术报告风，页面承担可回看的主要解释，备注补足口头展开。

## 双向设计与修改

可以从内容母稿、已有页面或难点口述中的任一处开始。按实际缺口往返调整，避免先把页面定死，再强行把一篇独立文章塞进备注。

1. **确定本页任务与已有基础。** 沿全场主线明确这一页要让听众理解什么、上文已建立什么、下一页将接什么。读取真实图表、标注及可见文字；已有PPT既看对象内容，也看渲染图，不能仅凭标题或文本抽取编讲稿。
2. **将讲述动作落到图文。** 先写一版完整解释或短口述草稿，逐段对应当前页的具体内容。图表页说清关键变化和含义，机制页沿一次操作追踪，比较页说明比较维度及差异。段落组织服从本页任务，不每页套“首先—其次—最后”。
3. **用讲稿发现并修补页面。** 若讲清楚必须补一个变量、关系、背景或算例，判断应加短定义、箭头、图注、局部放大、中间状态还是关联页。只有必要的可见支撑进入页面，不把整段备注粘上去；已清楚的页也无需为了证明双向性而改动。
4. **用最终页面反校讲稿。** 调整文字、图形、排版或页序后，重写实际指图和承接；不存在的颜色、位置、数值、动画状态不能留在备注。新增事实仍关联原有来源台账，教学类比不升级为产品实现。
5. **成对检查并估时。** 同时看页面与完整口语稿，确认叙事落点、自然停顿、主要解释和翻页时机，再估算讲清楚所需用时。联动修改与最终文件检查见下文；时长服从[时间预算](presentation-pacing.md)。

需要协作或追踪难页时，在既有内容卡中简记“讲述片段 → 当前P/B、图中对象或状态 → 必要补充 → 页面/备注改法”。这些是内部制作记录，不写入演讲正文，不为每句话另建ID；小任务可直接对照修改。

### 备注新增内容的取舍

| 新增内容的作用 | 处理方式 |
| --- | --- |
| 用日常语言解释当前标签，或补一句理解当前动作所需背景 | 在备注自然展开，并接回具体对象；已有页面足以跟随时无需加字 |
| 引入本页结论必需的新变量、步骤、因果或比较依据 | 将最小充分的图文支撑补到本页，调整布局或用连续状态页；不能只让听众凭记忆补齐 |
| 背景本身包含独立技术过程，需要持续解释 | 在它真正发挥作用的位置组织关联页或前置基础，再回到主线；不要让原页作为无关静态背景 |
| 内容有用但属于另一页、进阶支线或答疑 | 移到相应页面、作者详解或附录；本页只保留必要承接，关键前提不能随支线一起移走 |
| 与当前论点无实际关系，或没有证据支持 | 删除游离叙述；必要的新事实先补证，不靠扩写凑备注长度 |

新增页不是唯一修法。紧凑页可采用同图的局部标注、对照小表、放大面板或分步状态，让解释和证据保持邻近；整组编号、技术标号和连续图例仍稳定。动态呈现时核对当时已可见的对象，不能在对象尚未出现时长讲它；没有实际动画时不写“点一下就会出现”。

用户只允许修改备注时，在现有图文和授权资料内改善讲述，不擅改页面或假装新增图形已经存在。若关键过程缺少可见支撑，就说明具体页面缺口与最小修法；已获整套修改授权时直接联动修复，无需另设批准每页的步骤。

## 流畅的专业口语

遇到同名量、符号换义、整体/部分或教学例子更换，按[用语与理解对应](ppt-language-clarity.md)检查具体误读与必要交接。把决定听众推理的对应补到页面或清楚的邻近标注，再沿其口述；不因防误读而给每段添加排除说明，已有清楚背景可自然沿用。

优先使用顺口、听一遍能接住的表达，保留准确术语与必要细节。将一口气塞进多个动作、条件和插入语的长句，按实际过程拆成有自然停顿的短句或中等长度句；用句号和段落形成节奏，不只是把长句换成更多逗号，也不拆碎一个技术概念。必要长句可以保留，不设单句字数上限。

- 先让听众知道动作主体，再说操作和结果；长定语可改成前置解释，名词串可改成动词过程。
- 数字、符号、缩写与页面一致，按顺序说明含义再用于推理；不为顺口舍掉关键精度或擅换术语。
- 在新概念、关键比较及中间结果处允许自然停顿。默认用可直接说出的句子和标点体现节奏，舞台指令、估时及内部映射留在制作记录。
- 指图语言只在确有帮助时使用。可以说“输入先到候选生成这一步”，不必每段说“这一页”“大家看”；更不能用这些开场词掩盖后续游离。
- 技术限定沿[集中简述](writing-and-editing.md#ppt技术限定的集中与简述)处理，不因讲稿变长又恢复逐段免责声明；来源仍默认留在台账。

### 假设教学示例：让讲稿补出页面缺口

原页只有“输入 → 固定选择 → 输出”三个框，备注却准备展开候选生成、选择索引与两次输入的差异。这些操作属于当前核心解释，应补可见过程，不能让三个粗框陪着长篇口述。

一种可行修法是在流程中加入“生成x、2x、3x → 选第1和第3项 → 相加”，旁边放两行对照：x=2对应2/4/6、结果8；x=3对应3/6/9、结果12。备注随后可以写：

> 输入先到候选生成这一步。这里把x分别乘1、2、3，得到三个候选值。然后按固定映射，取第1项和第3项相加。
>
> 看旁边两行算例。输入是2时，三个候选是2、4、6，选出2和6，结果就是8。输入换成3，候选变成3、6、9；选的位置没变，结果变成12。
>
> 所以，能复用的是选哪两个位置。输入变了，候选值仍要重新算。图里的固定映射省下了重新建立选择关系这一步，并没有省掉全部计算。

这是教学设定，不是产品性能证据。它展示了备注推动补图、再按最终图文改稿的过程；不要求真实技术页照用这套模块或句式。若页面原本已有等效算例，就直接沿现有标号讲解，无需重复加表。

## 成对验收与修订

沿最终实际页序逐页检查页面与完整备注，必要时连读相邻页：

- **页面到讲稿：** 本页的核心图文、关键差异和主要因果是否解释到位？不以每个元素都念过或关键词命中代替理解。
- **讲稿到页面：** 每个主要讲述片段在当时可见内容中落在哪里？新增背景是否服务当前对象，是否已经成为没有视觉支撑的独立长段？遇到后者，回到页面共同修改。
- **口语与读序：** 是否有连读拗口、少停顿的长句、悬空指代、未解释符号或来回找图？是否讲了错误的行列、颜色或尚未出现的对象？短背景是否自然返回当前过程？
- **完整性与用时：** 讲清本页所需的步骤、例子和理解停顿是否齐全？超出原估时先改预算或组织，不删关键解释凑秒数；也不添加无信息增量的文字填满预算。

口语稿若连续讲述页面无法支撑的新过程，导致听众失去叙事线，按S2修复；同样处理“只有备注讲清楚，页面仍无关键过程”或“页面有关键图，备注却绕开”的情形。短而必要的背景、自然转场、没有朗读所有辅助参数都不自动算缺陷。

修订后沿P/B与素材关联同步页面、备注、读序、首次定义、邻页承接和时间账。最终PPTX重新导出并检查实际渲染与完整备注，旧预览或旧备注不能证明新版本一致。纯文本/模型回读只证明相应审阅范围；作者真实试讲或录音检查发生后才能记录为实际演练。无需为修改技能规则自动制作用户PPT或强制作者先试讲。
