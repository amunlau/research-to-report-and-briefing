# 版本与项目升级

## 2.0.0

保持技能名称与调用方式，在1.2.1的研究、报告、讲稿、作者解释和项目记忆基础上升级，重点为高质量PPT及全部成果的自然专业文字。

### 本次增加与调整

- 明确从零、用户材料、混合资料三种输入模式，区分材料用途、来源权威、保真和事实核查，按关键缺口补证。
- 全部读者文字共用语义编辑方法，分别处理报告、页内文字、图注、汇报稿与技术解析，包含标明假设的改写例；不以机械禁词或压缩细节代替编辑。
- 增加15类技术与汇报页型，以及按实际ppt-master版本选择路线、转换内容、保存身份、处理原生对象与验证最终文件的适配流程。
- 增加独立内容契约：来源、事实、素材、章节和页面对应；未知、分歧、推导、假设和可见限制分别处理，追踪跨成果修订。
- 增加只读内容引用审查与PPTX库存助手；它们输出可判定发现，不能证明事实正确、图表合理或目标应用渲染通过。
- 加入阅读型高密度视觉示例和执行集成说明；按需调用既有能力，明确并行职责、资料复用、变更传播与检查范围。

### 同版本补充：页面解释与演讲支持

本节补充继续纳入2.0.0，版本号保持不变。

- 默认兼顾讲述与阅读，页面保留完整要点、因果条件、分类解释和图表读序；标题可为内容概要、问题或有据观点，与全场主旨相连，不强行每页结论化。
- 默认逐页写入可直接照读的完整口语备注；普通内容页约30—90秒为参考，封面/过渡可短、复杂页可长，用户可关闭或另定时长。备注对应最终页面，实际PPTX需检查完整备注，不能仅凭源稿或统计宣称交付。
- 增加市场趋势、技术细节、工作汇报三类可选论证路径；页型在原12类基础上补趋势与驱动、目标与进展、风险与待决事项。页数没有固定范围，不照搬参考材料篇幅。
- 常规标题与正文默认微软雅黑、浅底深正文的蓝色系克制科技风；明确用户、品牌与模板选择可覆盖，公式/代码/专业原图保留适合的字体和语义颜色。
- 同步内容契约的可选notes_enabled、时间账示例、视觉偏好、项目记忆模板和制作适配。预算示例展示不同节奏，不代表实际排练；默认值不自动填充或生成成品。

### 同版本补充：第二轮公开技能调研

继续保持2.0.0。重新检索并对照公开技能的实际入口、关键规范和实现，保留本技能的研究主线与PPT Master制作分工。吸收的是独立编写的方法，未打包第三方代码或新增运行依赖。

- 增加按需读取的“排版测量与局部修复”：真实字体、中文与西文混排、内边距/缩进/行距、真实模板槽位、科学图适配及意图重叠。容量估计不替代目标应用渲染，不通过持续缩字或自动裁切隐藏问题。
- 补充定稿计划到最终成品的保真检查，分别核对正文、表格行列、图表数据、原图面板、公式关系和完整备注；只匹配关键词或统计对象不能算通过。
- 深化原图直接观察与论证边界、图号与图注实际配对、缺失数据和独立统计单位；质疑先区分检索、口径、计算、逻辑与范围，再处理相应缺口。
- 将理解任务、问题与证据回扣、最终可见元素到讲述动作进一步具体化，保留自然专业文字和完整口语备注。
- 细化必需对象/备注丢失警告的处置、渲染输出身份、依赖变化后局部重做、手改稿保护和紧凑页级协作；验收回执示例增加内容保留、渲染环境、逐页记录及历史复用位置。

开发调研的原始工作记录不作为运行依赖随包分发；采用的方法及出处见[执行与集成](execution-and-integration.md)和[排版测量](layout-engineering.md)。源码静态阅读支持方法取舍，不能证明实际成品改善幅度。

### 同版本修正：行为检查与适配复核

本节记录2.0.0开发期间的行为复核修正。

- 内容助手现在读取备注开关：默认/显式启用时，空稿在草稿阶段提示、最终阶段报错；关闭时允许为空。该检查只判断非空，不代替口语质量或最终PPTX核对。路径契约及解析同步拒绝NUL等控制字符。
- 绑定预期交付的快照在配置变化或丢失时正确报告差异；成果被同名目录替代也报告差异，而非输入错误。旧配置迁移备份按原始字节保存，保留BOM与换行。
- PPTX库存助手增加可选`--include-text`，导出完整原生段落与备注供比较；默认输出兼容。XML顺序、图片/图表文字、公式和继承对象等边界明确保留。
- 引擎Fact IDs只映射符合其外部来源契约的项目，用户材料、推导与假设保留各自证据身份。明确POTX读取与原生编辑能力不同，修正完整备注的指图与句数冲突，并说明已明确授权时的连续推进方式。
- 同步配置路径覆盖范围、快照绑定范围和派生素材复核说明；未增加运行依赖。

### 同版本修正：综合复查与轻量任务

本节修正继续纳入2.0.0，未改变配置版本。

- 内容助手按JSON Schema整数语义接受有限的`1.0`，继续拒绝布尔值和非整数页号；计划几何比较仅对浮点算术尾差加入极小容差，真实越界及非正尺寸仍报错。
- 制作映射的事实/来源编号必须非空，素材映射复用既有项目相对路径定义。原项目若使用反斜杠、绝对路径或父级跳转，按实际项目文件位置转为相对路径；一般CLI文件参数仍按宿主规则使用。
- 项目记忆和安装助手统一拒绝JSON重复键，避免后值静默替换前值；安装检查同时拒绝非有限数值。含NUL的项目路径及解析失败返回清楚的结构化错误，不再随Python版本表现为异常堆栈或误判为计划文件。正常BOM、Unicode、迁移原字节备份与快照继续兼容。
- 澄清小任务可以使用等价内容卡与单值估时，复杂任务再展开机器账本和时间范围；保留必要证据、完整备注及总时长统筹。页面采用面向读者的短来源或引用号，完整书目放在来源页/清单，口语稿不混入检索台账。

开发期间采用脚本前后复现、既有回归、独立复读及三页闭卷内容试用，公开摘要见[验证范围](../docs/validation.md)。检查覆盖Windows Python 3.12与3.14的相应运行路径，不代表Linux或宿主加载实测；三页文字样稿不代表已生成或渲染PPT。未增加运行依赖或新的固定页数、字数、时长配额。
