# PPT用语、对象与理解对应

用于生成或修订PPT标题、页内文字、图注和备注，以及定位“术语认识，但整页仍读不懂”的问题。通用写作及修改权限沿用[写作与编辑](writing-and-editing.md)；本文件细化可见表达、误读诊断和跨页语义，不替代调研、制作或渲染，也不强制加载全部其他参考。

## 先确定本页的理解任务

沿已确定的听众基础与用途，说明本页要让人认清对象、跟随过程、读懂结果、比较选择，还是形成判断。默认仍面向领域小同行与相邻领域人士，采用hybrid；用户明确的受众、talk/reference用途和编辑范围优先。技术入门页多补必需定义，专家页可沿用共同基础，不把所有术语重新解释一遍。

标题、图文和口述围绕同一主要任务，可以承载多项有关联的认识。以下四问用于内部审阅，答案不需要逐页印出来：

1. 暂不看备注，能否用自己的话说明本页的任务及主要认识？结论页应有结论；机制页可说明关系与过程，参数页可说明对象和字段，导航页完成定位即可。标题可用概要、问题或有据观点，不把没有评价句自动判为失败。
2. 影响推理的名词、符号、数字和图示能否对应到具体对象、范围或状态？必要时补形状、单位和时点，不要求常用词每次写全定义。
3. 是否能辨明真实输入、观察结果、条件计算、假设和作者解释？按实际误读风险补短身份，不在每处复制标签、出处和免责声明。
4. 页面是否已有主要解释和关键对应，备注是否沿其展开？看不懂主要关系时联动修页；页面已有充分支撑时，备注可以自然补充短背景，不必把全部口述再抄上页面。

判断来自实际内容检查。模型写出复述不等于真实听众已理解；图、文字或语音未取得时，明确相应未查范围，不凭标题、清单齐全或“可读性提高”自评验收。

## 从具体误读选择修法

定位到实际原句、图中标记或表格字段，写清它可能使读者把什么理解成什么，以及这一差异怎样影响计算、操作或判断。用原材料确认正确含义，再选最小有效修法；没有实际歧义时保留原文，不为了填写表格臆造误读。

内部可用一行记录：**位置与原文 → 具体误读 → 依据及正确关系 → 修法/待核 → 受影响位置与复查**。例如“P012的‘输入’ → 可能指整个向量，实际正在追踪x₂ → 由本页公式确认 → 补‘向量x的第2个元素’，将贡献箭头连到对应输出 → 同步图注和备注”。不确定究竟指哪种对象时先列待核，不能选一个看似合理的对象补进去。

生成时在内容卡上解决这些缺口；改写时在授权范围内处理；仅审阅时交定位意见。以下十四项是诊断方向，沿用现有六类根因及S1—S3影响等级，同一根因合并关联位置，不要求每页发现问题或另交十四张清单。

| 检查方向 | 实际障碍与修法 |
| --- | --- |
| 名词堆叠与压缩句 | 多个对象和结果仅靠“与、协同、构成”等相连，读者无法还原关系。先明确主体、动作和因果，按有意义的动作拆句；不要把顺畅的必要长句机械拆碎。 |
| 判断被机制清单替代 | 对本应评价或收束的页面，从已有依据和备注找回真实判断，机制作为依据；不能为机制介绍或参数检索页强造评价，缺证时不补口号。 |
| 观察、结论栏只有主题词 | “质量、交付、扩展”没有说明发现或取舍。补有依据的完整认识，或删除空栏；观察可只描述结果，解释、判断与建议分别表达，不强制观察带立场。 |
| 未解释术语与特殊技术义 | 首次使用且超出听众基础时，用对象及用途说明，再对应术语。仅对具体易混义补排除说明；类比作辅助，不能将原技术动作直接换成类比词。 |
| 对象、范围与形状不明 | 整体与部分、数学行与版面行、请求与步骤被混称。补足改变理解的对象/形状/时点；流程按需要交代执行者、载荷、去向与可用条件，不凭常识发明接口行为。 |
| 关键对应缺失 | 位数、乘法因子、下标或箭头没有说明在数谁、选谁、连谁。把决定计算的对应放到邻近公式、图例或数字旁；先确认编码空间等前提，再解释结果。 |
| 页间或图文缺少交接 | 图、表和旁注沿不同路径，或新例子被当作原例续算。同步真实读序，简述必要变化；清除旧图注时保留仍有用的单位与条件。 |
| 可见标记悄然换义 | 连续讲述中同一字母、颜色或编号换了对象。必要时改名或局部重标，追踪后续使用；独立图表有明确图例时可复用标记，不实行全稿字母或颜色唯一制。 |
| 证据身份混淆 | 官方披露、文献方案、假设和计算被写成相同的确定事实。按契约分别核对来源、性质与支持状态；只在决定含义的位置简述身份，不把来源类型当作可信度等级。 |
| 同名量与单位混用 | 局部时延当作整次请求时延，索引宽度当作数值精度，GB/GiB或bit/byte混算。首次并置时分清对象和单位，检查是否真的同口径；名称不同但含义相同也不制造虚假差异。 |
| 图注无法帮助读图 | 图题、图例与旁注合起来仍不能说明要读什么及口径。补对象、关键关系和必要条件；定量图检查轴与单位，架构图检查边界和流向，不给无坐标的图硬套横纵轴。 |
| 页面与讲稿信息错位 | 关键关系只在备注，或讲稿离开当前图长讲另一过程。按[共同设计](slide-notes-alignment.md)双向修复；不要求逐字对称，也不在只改备注任务中擅改页。 |
| 教学或推导被当成实测 | 真实参数代入算式不产生新的测量，教学恒等不证明产品可省略计算。保留输入身份、公式前提与结果性质；结果仍需复算，标签不能替代正确性。 |
| 口号化或把页面写空 | 拆句后丢了对象、机制、条件或比较基础。回填有效信息，利用图文、短段落和层次组织；清晰不以字少、大字号或统一短句衡量。 |

## 对象、符号与数量的清楚表达

定义以能完成当前理解动作为准：先建立对象或具体动作，再接术语与符号；熟悉的专业用语可以直接使用。短标签、完整句、图例和公式可共同完成定义，不固定“是……不是……”句式。必要排除说明只挡实际可能发生的误读，不扩展成列举所有错误理解。

重点检查这些关系，材料未给出的部分不能靠写作补造：

| 易混关系 | 应核对的内容 |
| --- | --- |
| 整体与部分 | 输入向量/当前元素、矩阵/行列、会话/请求/步骤、模块/局部缓冲；当前计算到底作用于谁 |
| 索引、格式与精度 | 编号所覆盖的集合、计算格式位数、实际存放位数、有效精度；它们是否相等须有依据 |
| 过程与产物 | “对记录编码”与“编码后的序列”，“执行调度”与“调度结果”；代词可自然承接已清楚对象 |
| 局部与系统量 | 取数等待与端到端时延、单用户生成速率与聚合吞吐；不能仅因同单位就直接比较 |
| 单位与统计口径 | bit/byte、十进制/二进制进位、单/双向、每设备/聚合、均值/中位数/分位数、峰值/持续值；缺失的统计或来源身份不猜补 |
| 约定与状态 | 行/列向量、矩阵乘法方向、从0/1起始的索引、坐标原点/正向、时间点与状态有效区间 |

对公式先核对对象与维度，再复算中间量、单位换算和结果。维度已经清楚时可以用紧凑标记，如`x∈R^(1×4)`；无需每句重复“1行4列”。带量长句按量的含义和条件拆解，不能为口语流畅擅自增加“厂商披露”“实测”“配置上限”等原材料未给出的身份。

对于确实容易混用的词或标记，可在已有内容卡简记“采用义、易混义、首次定义P/B、适用范围、换义位置、后续使用处”；同一条记录可以包含符号和例子变化。小任务直接对照即可，长任务按风险维护，不新设三套必填表，也不要求每批向用户交完整词表。

## 图表及页型的表达分工

| 页型或对象 | 页面应帮助完成的认识 |
| --- | --- |
| 判断、评价、收束 | 从依据形成有范围的判断；观察结果、解释和建议可以分开，不要求每块都有三段文字或重复同一结论。 |
| 机制与系统 | 明确系统位置及当前要读的关系；按任务追踪一次操作，说明改变了哪项工作。现有图与文字已足够时不另添评价栏。 |
| 计算、推导与教学 | 对象、必要形状、选择/计算步骤和中间结果可跟随；真实输入、教学假设、推导结果分别表述，页型本身不决定证据身份。 |
| 原图、论文或专利图 | 给出与本次对象的关系及读图入口；技术图本体优先，标号与旁注对应。能否称为产品实现由采用证据决定，不由图片出处的名气决定。 |
| 对照表与路线参照 | 说明比较轴及可比范围。不同条件可作资料汇总或取舍参照，不能用无依据的分数、色彩或“全面胜出”暗示同条件实测；不适用、未给出和未核实分别记录。 |
| 时间线 | 分清披露日、发布日、实施日与计划日期。混合节点可逐项写“公布、上线、计划”等准确动作，不必强制全图只有一种日期；规划与已发生事件不能混成已交付。 |
| 数量、容量、速率图 | 标题、轴、图例与邻近说明共同交代关系、单位、基线和必要条件；不同系列的实测/推算身份不能被合并。无需在图注重复所有轴标签或每图附“不是什么”。 |
| 封面、目录、导航、结束 | 定位、路线和衔接明确，目录及引用同步；不硬加技术结论，也不首次抛出未经解释的新主张。 |

图注只补图与标题尚不能表达、却影响解读的信息。明确的观察句可以是“此次记录中，中位数由120 ms降至90 ms”，不必再添立场；因果解释和行动建议各需相应依据。页面内的审查占位语如“本页尚未下判断”“此处不能写死”不能自动成为成品文案：可继续补证时按权限补证，确需保留的缺口用具体业务或技术表述，工作状态留在记录。

“教学算例、情景估算、厂商测试”等必要身份与书目分开。来源、事实性质和支持状态沿[内容契约](content-contract.md#id与状态)记录，不强行五选一；共用条件按[集中简述](writing-and-editing.md#ppt技术限定的集中与简述)交代，来源仍默认留在台账。真实参数的理论推导不标成虚构教学参数，作者判断也不能作为掩盖证据缺口的标签。

## 跨页承接与双向同步

按实际认识路径检查连续页面，也检查改动传播到哪些未改页：

- **符号和例子：** 当前对象是否仍是前页对象，输入、尺寸、矩阵、码本或计算方向是否变化。变化影响后续理解时，在当页以短定义、图例或直接差异说明交接；保持不变的约定无需逐页声明。
- **图文读序：** 图中路径、旁注编号、步骤表和口述是否指向同一操作；空间顺序不同时可通过准确编号或引线建立映射，不要求所有图都从左到右。
- **语义编码：** 连续推导保留标号和图例；独立图表依靠清楚的局部标签说明含义。颜色可承载层级或强调，不要求装饰性主色具有数据图例；类别区分不只靠颜色，也不为全局唯一性增加大量颜色。
- **数量与证据：** 同一数字进入新负载或新算式时，核对条件、单位及推导身份；不能把原测量直接外推。图注和备注随实际图更新，删除旧脚注前保全其有用口径和来源映射。
- **导航与依赖：** 同步首次定义、实际页码、目录、交叉引用和讲稿转场；保留稳定ID。只改局部时检查必要邻页和引用处，不自动扩大修改权或要求用户补交整套材料。

备注可以先揭示缺少哪一个对应，再指导补图文或改读序；按[页面与备注共同设计](slide-notes-alignment.md)往返完成。已有页面清楚而只要求改备注时，直接改口语；只靠备注确实无法修复页面误导时，说明剩余缺口，不声称原页已经修好。关键解释要可见，普通补充不必与页面逐字相同；不要求每页都依次“命题—指图—挡误读—总结”。

## 经复算的表达示例

以下只演示表达和推理检查，不是产品证据，也不是通用实现建议。新增算例应先定义设定再复算；不能因已经写“教学”就放过错误。

### 一个元素怎样贡献到输出

含糊句：“输入与矩阵相乘后累加到输出。”

在明确的行向量教学设定下，可写：`x`为`1×4`，`W`为`4×8`，`y=xW`为`1×8`。本页跟踪`x₂`：它分别乘`W`第2行的8个系数，把8个乘积加到`y`对应分量，贡献为`Δy_j=x₂W_(2,j)`。图中将`x₂`连到该行和对应累加位置。“第2行”由矩阵标签明确，不再与版面第二行混用。

这说明一个元素的贡献，不代表全部输出已算完；其他元素仍按同一规则贡献。后级是否等待全部分量、怎样写回，由实际接口和时序决定，不能仅从乘法公式补造同步屏障或原子写回。

### 原始索引与子集内索引

含糊句：“从8个候选选4个，所以索引只需2位。”

若字段直接编码原来8个位置，固定宽度索引需3位。若已知子集是`{0,2,5,7}`，双方共享映射`00→0、01→2、10→5、11→7`，子集内选择才可用2位。页面应放出正在使用的映射，说明2位在选择哪一组对象；映射如何存储或传递、是否计入成本另按实际设定核对。不能从“更稀疏”直接推出索引总成本下降。

### 计算量级与条件比例

教学设定：每层有32,768个元素、共32层、每元素实际存放8位，不计其他存储项。总量为`32,768×32×8÷8=1,048,576 B=1 MiB`。只凭这些条件不能得到8 GiB；有其他维度时应补完整公式及其依据，不能为了保留目标结果倒推参数。

在元素数与存储模型不变时，实际存放位数从8增至16，总量为2 MiB。这里存储量翻倍成立；它不等于有效精度翻倍，也不保证有对齐、压缩或元数据的真实系统总占用恰好翻倍。页面可用紧凑的条件行、公式和两行对照表达，不逐处重复整段限制。

### 让评价有内容，同时保留观察身份

假设材料只报告某次同口径记录的中位数由120 ms降至90 ms，未隔离其他变化。可见观察可以写“此次记录的中位数下降25%”；计算为`(120−90)/120`。这不是“性能优化”主题标签，也不需要强加行动建议。若要进一步解释是哪项修改导致下降，还需对应证据。

评价任务则从已有依据提出范围明确的判断，例如在另一个明确教学设定中，甲方案需修改接口、乙方案保持接口，当前目标要求接口不变，可以评价乙更符合这一约束；不能据此推导乙速度更快。结论、依据与取舍按实际信息组织，不强制另加“观察”栏或重复标题。

## 验收与采用边界

检查本轮授权范围内的理解任务、对象指认、数量对应、证据身份、图文读序和口语贴合，沿[质量规则](quality-and-versioning.md#定位问题与复查)记录具体问题。正常表达允许保留；不适用、未检查、待核与实际失败分别记录，不把形式清单全部打勾作为验收。实际PPT仍须检查渲染和完整备注；纯文本审阅不能证明字号、遮挡、演讲用时或听众理解。

本参考依据用户提供的《PPT用语与表达增强：通用技能提示词（全文）》及确认的取舍独立整理，吸收十四类诊断、对象与量纲区分、例子更替和跨页检查。纠正容量算例、索引前提以及把所有推导当虚构教学的做法；观察不强制带立场，证据保持多维记录。完整任务可内部校准后连续执行，不增加强制样张审批、全稿表单或新分类；用户要求分阶段时按约定停止。沿用克制配色、紧凑字号、共用限定简述、默认隐藏书目和双向备注设计，不将外部提示词全文作为新的总规则，也不依赖原文件或其本机路径运行。
