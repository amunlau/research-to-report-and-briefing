# 执行效率、工具集成与协作

用于较长研究、多来源PPT和成套材料。效率来自按需加载、复用有效证据、隔离写入和只重做受影响内容，不以减少必要研究或跳过渲染换取速度。

## 先确定本轮最短有效路径

- **只有主题**：问题与覆盖框架 → 来源与事实 → 机制/论证 → 请求的成果。
- **资料充足、要求转制**：资料接入与关键核对 → 内容组织 → 制作；不重复做无关全网综述。
- **资料不完整**：沿现有材料定位缺口，只补影响判断和页面的部分。
- **已有成品修订**：确定基线与改动 → 更新受影响事实/页面/讲稿 → 针对变化复查。
- **只要PPT**：保留证据和可用内容母稿，默认生成最终页对应的完整演讲备注；报告全文和独立讲稿文档按需另做。
- **只要报告**：完成问题覆盖、章节论证、正文图表与引用、摘要结论及实际文件检查，写回项目状态；不启动PPT制作、备注或时间预算。

研究、正文和图表的规模由目的决定；不自动生成用户未请求的文稿、演示视频或独立网站。用户已明确授权的完整工作连续推进，内部完成检查后可继续，不为默认模板中的阶段标签反复询问。真正影响范围、保密边界或不可推定的内容决定再询问。

## 运行时能力发现

从当前环境的技能目录和工具清单确定可用能力，再读实际入口和必要参考。记录影响复现的版本、字体、渲染器与已选路线。避免把某台机器路径、某个仓库README的最新能力或截图中的环境假设固化到技能。

跨Codex/Claude Code或Windows/Linux运行时，按[环境与跨平台适配](portability.md)处理技能发现、解释器、路径和渲染差异。本包的安装不会自动提供其他skills或联网服务；从实际工具清单选择能力，缺少专属并行/预览工具时使用顺序执行/文件交付。制作引擎替代须保留本次要求的内容、备注及编辑性，不能静默退化为整页图片。

| 职责 | 首选使用方式 | 缺失时的处理 |
| --- | --- | --- |
| 总体研究与跨成果组织 | 本技能 | 保留一个主流程，避免多套技能同时改范围 |
| 搜索、全文、学术元数据 | 当前可用搜索与文档工具；已有Exa/Tavily/Firecrawl等按需选一个 | 用可用检索途径；披露关键来源实际不可达，不虚构阅读 |
| 深度分项研究 | 已安装research系列的对象/字段方法；可用助手分工 | 单代理逐项做，记录同一覆盖表 |
| 历史与横向比较 | hv-analysis等相关方法，只取适用的演进/竞争轴 | 直接依研究问题组织，不强加每题都写长历史 |
| 专业原图 | 可用PDF工具，或已安装figure-extractor/paper2assets | 高分辨率原页定位与裁切，保留图注和来源；表格另核对 |
| 数据图 | 真实底表与科学绘图库；适用时scientific-visualization | 使用准确可读的表格或基础图，不能编造数据补视觉 |
| PPT制作 | 可用ppt-master，细则见[ppt-production](ppt-production.md) | 使用当前可用PPTX制作工具并披露编辑性；没有实现能力时交付真实中间材料与缺口 |
| 目标文件渲染 | 可用PowerPoint/WPS/Office能力，或合适的已安装渲染器 | 源预览可继续帮助改布局，但不得标实际PPTX已验证 |

联网研究本身不要求安装新技能或购买服务。需要新的依赖时先说明必要性，遵循当前环境和用户授权；不自动修改系统配置、上传私有材料或开通付费服务。

## 吸收其他技能的方法

以本技能的任务范围和内容契约统筹，外部技能负责其明确阶段。采用之前读实际版本，识别密度、字体、配色、标题、备注、确认、生图、编辑性和工具依赖的冲突，并按用户要求处理。PPT的讲述支持、微软雅黑、蓝色基础、同级配色、所选模块样式和完整备注须映射到工具实际选项，不能被工具的“少字”“无备注”、默认彩条卡片或“每页观点标题”悄然覆盖。报告单独映射[报告格式](report-formatting.md)的宋体/Times New Roman、黑色文字、首行缩进及可见章号，不继承PPT样式。用户的明确项目选择优先。

交接同时落实[视觉表达](visual-expression.md)中的紧凑内容、容器选择及默认关闭页内来源，将出处写入备注的独立资料分区；不能只改配置示例而沿用引擎的来源页脚或大色块母版。引擎完成后按[排版测量](layout-engineering.md)复查最终文件，结构扫描不能替代文字碰撞和图内标签检查。

- **ppt-master**：制作路线、视觉系统、原生对象和实际导出；以其当时可用的输入结构为准。
- **scholar-slides / paper2ppt**：论文图表、源句/论断对应、真实表格和结果边界；不强制把产业研究改为单篇论文汇报。
- **research-ppt / PPT-Design-Skill**：语义页型、科学技术版式和图证位置；不把模板占位图或宣传中的风格数量当成质量证据。
- **K-Dense研究/引用技能**：问题、证据矩阵、反向检索与书目核验；书目字段和论断支持程度分别检查。
- **academic-pptx / scientific-slides**：全场论证、知识递进和时间安排；少字/大留白规则仅在实际演讲场景适用。
- **中文研究与写作技能**：借用来源消化、内容母稿和具体技术表达。项目应保留研究对象与作者声音，避免多轮改写逐渐变成统一宣传语气。
- **模板与制作辅助技能**：pptx-from-layouts/Jinba的真实模板槽位和继承测量、siril9的可见内容保留与渲染回执、slides_maker的依赖指纹可补充特定环节。先核对实际实现和依赖，不整体引入其字数、配图、标题或交互配额。

本包提供独立编写的流程、契约、页型说明和检查助手；没有打包第三方制片引擎。外部调用遵循其当前有效说明。复制代码、素材或模板前另核实对应许可，不能以“参考过方法”推定可以复制实现。

## 保护输入和既有成品

修改前识别输入原稿、可编辑生成源和现有交付文件，记录相关文件的内容指纹及可恢复基线。构建结果先写到项目内独立候选路径；不要在生成或转换失败时留下半写入的正式文件。只比较文件日期不足以发现手改，重复构建也不能推定相同文件名仍代表原版本。

候选生成和必要检查完成后，重新核对将被替换的目标是否仍与开始时的基线一致；一致且本次任务授权更新它，才使用当前工具支持的安全替换方式。替换失败保留候选与原文件，并记录真实状态。发现目标或生成源在执行期间变化时，保留双方，识别新增改动再合并；无法可靠合并时另存候选和差异，说明需选择的冲突，不直接覆盖用户修改。不要把指纹变化自动归因为用户手改，它也可能来自另一构建或保存过程。

上述记录属于既有制作记录，无须为每次编辑复制整套工程。恢复时以当前实际内容和已知基线为准，不用历史“已完成”标签跳过漂移检查。

## 并行与整合

适合独立分派：来源族取证、同一比较表的独立对象、专业图搜集、单独章节初稿、技术审阅和语言审阅。每个分工先约定问题范围、输入版本、交付字段与写入位置，提供所需最小上下文；不要让多个助手同时改共享配置、事实ID或最终PPT。

汇总者负责同源去重、参数口径、跨章节术语、矛盾处理和论证一致性。审阅者收到真实材料和具体问题，独立指出证据与表达缺陷；不要求给出预定分数或固定数量批评。没有并行能力时同样采用这些职责顺序。

页级制作可并行时，交接一个紧凑页包：页ID与本页任务、`P/B`内容及读序、事实/素材引用和实际路径、采用的视觉配置/模板版本、目标编辑性、完整备注及允许修改范围。只附理解本页所需的章节上下文和相邻页过渡。接收者返回页面源位置、内容指纹、变动ID、对象映射及未决警告；不重新编号共享事实，不直接覆盖最终PPTX。汇总者顺序合并页面源、检查跨页术语和过渡，再统一构建；外来单页PPTX只有在实际引擎支持依赖完整合并时才采用，不能只拼页XML。

内部检查一般可由当前执行者修复后继续。需要独立审阅时选关键论断、最难页面或跨成果变更，不为每个段落启动昂贵的全套审查。涉及最终文件的独立审阅要绑定真实文件与版本。

## 复用与增量

原始来源按版本/日期/定位及必要指纹缓存；已确认且未变化的材料不反复下载。研究过程中先维护关键事实，解释性段落在写作时展开，避免保存多份相互漂移的摘要。

先做成本较低的路径/映射、必需内容、对象和几何检查，已知关键内容缺失时先修复，再成批渲染。使用独立且明确归属本次转换的输出目录，核对新输出与输入身份，避免读到旧PDF或旧页面图。LibreOffice并发或后台转换需独立用户profile；Windows可优先使用实际安装提供的阻塞式控制台入口。不要把进程已启动当成导出完成，也不要为清理失败任务关闭用户正在编辑的Office实例。

有现成可靠缓存时才复用转换结果：依赖应覆盖输入PPTX、渲染程序与版本、DPI/格式、字体环境和相关转换实现。支持按页失效的引擎还需覆盖页内容/关系及所引用媒体；主题、母版、布局、画布或全局字体变化会扩大失效范围。无法确认依赖身份、输出集合或图像可解码性时重新渲染；不为普通任务自行搭建复杂缓存服务。缓存命中不能自动生成视觉通过结论。

变更按依赖传播：

```text
来源更正 → 相关事实与计算 → 使用它的章节/页/图表 → 备注、讲稿、解析 → 受影响的渲染与验收
仅改间距 → 对应页面/邻页 → 重导出及视觉复查
仅换听众 → 讲述路径、术语前提、密度与讲稿 → 必要的页面重排
```

重新导出PPTX或PDF后，旧文件的渲染记录只能作为历史。若页面内容、映射和渲染图经对比可确认未变，可以引用该范围已有的审阅结论；仍记录本次成品身份、复用范围与依据，不把缓存命中或一次局部审阅扩成“全部通过”。

阶段结束保存当前输入、稳定ID、修改范围、已完成文件、未决问题和下一步。恢复时先读进度及相关内容块，再继续；无需重新加载全部参考或重做全部研究。
